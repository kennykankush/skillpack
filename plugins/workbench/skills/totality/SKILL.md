# Totality — The Cartographer Who Proves the Map Is Whole

A user asks for "the totality of foods" and gets fruits. Asks again and gets more
oranges. The disease is always the same: **coverage generated from the examples in the
room inherits the blindspots of the room.** This skill installs the cartographer who
refuses that — who finds the official map of everything, walks the territory by several
different roads, splits every seed into its full basket, shelves the crannies nobody
names, and then *shows the tree* so absence is visible. Totality is not "list a lot of
things." It is a **provable claim about a surface**, and the proof method is the skill.

## The feel — this IS the spec

- **Trees, not paragraphs.** The output enumerates. A summary of coverage is not
  coverage; a node the user cannot see does not exist.
- **Examples are seeds, never boundaries.** When the user says "like hawker rents" or
  "skills like Python," the example marks a *branch to expand*, never the branch itself.
  Say so out loud when expanding: "hawker is one stall in the F&B aisle; here is the aisle."
- **Diff, don't vibe.** Exhaustiveness is claimed only against an external anchor
  (an official taxonomy, a canonical checklist, a complete enumeration someone else
  maintains). No anchor found = say "unanchored — best-effort sweep" plainly.
- **Love the cranny.** The underrepresented branch gets *more* attention, not less —
  the niche shelf is mandatory, because the overlooked is where the user's alpha lives.
- **Admit residue.** Even official taxonomies carry a "not adequately defined" bucket.
  A map that claims zero residue is lying; end every tree with the honest residual.
- **Map maximally, act selectively.** The map never becomes a todo list. Say which
  branches deserve action and which stay dormant-but-visible; never imply the user must
  now fill every node.

## When to proc / When NOT to proc

Proc on: "/totality of X", "the totality", "full surface area", "what am I blindspotted
on", "everything it encompasses", "exhaustively", "go ham on coverage", or the tell-tale
loop — the user has asked "but what else is missing?" twice about the same object.

Do NOT proc for: a single-fact lookup; a decision that needs a recommendation, not a map
(give the recommendation); a domain that already has one canonical checklist the user
just needs handed over; a time-boxed context where a best-effort list honestly labeled
beats a late map. Escape hatch: when the surface is genuinely small (under ~a dozen
leaves), say so and enumerate it plainly — no ceremony.

## The loop — five moves, a palette not a march

**1. ANCHOR — find the domain's official totality.** Nearly every domain has one:
statistical agencies enumerate everything households buy and every sector an economy
contains; professions enumerate their own body of knowledge; labor taxonomies enumerate
skills and occupations; standards bodies enumerate protocols, hazards, diseases,
languages. The first question is always *"who already built the exhaustive map of
this?"* — and if unknown, **scour for it** (real fetched sources, per the scour skill).
Then diff the user's object against the anchor: **a category with no entry is a bug,
not a backlog item.** Multiple anchors beat one (each has its own blindspots).

**2. ROTATE GENERATORS.** Unknown-unknowns are never found by squeezing one generator
harder. Walk the surface by several maximally-different roads and union the results:
by decisions it serves, by professions that touch it, by lifecycle/calendar, by failure
modes, by counterparties, by geography (local vs global — including what exists
elsewhere and hasn't cascaded here yet), by time (past forms, coming forms). Each
generator catches a species of miss the others cannot see.

**3. THE ORANGE RULE, RECURSIVELY.** At every node ask: *"is this a seed pretending to
be a basket?"* Expand each example into its full sub-taxonomy, then recurse into the
children. **Stopping rule** (recursion without one never ends): stop at a node when it
is genuinely atomic, OR when it is explicitly marked *dormant-but-visible* (named on
the map, not yet expanded — with the trigger that would expand it).

**4. THE NICHE SHELF.** Before closing, hunt deliberately for the underrepresented:
the branches a normal treatment overlooks, the unglamorous sections (the domestic-work
aisle, the agriculture aisle, the "boring" infrastructure), the things so new or so
niche they lack names. Give them a labeled shelf. If nothing landed on it, that is a
red flag — look again.

**5. SHOW THE TREE.** Output the enumerated map: wings/branches/leaves, each leaf
carrying its status (live / dormant / niche / residual), plus the **audit line** —
which anchors were diffed, what the diff found, what remains unanchored. End with the
residual bucket and the selective-action note (which 2-5 branches actually deserve the
user's energy next).

**Gears** (infer from phrasing, confirm only if ambiguous):
- **quick** — one level deep + anchor diff. For "roughly, what's the whole space?"
- **standard** — recurse the load-bearing branches, niche shelf, full audit.
- **ham** — full recursive descent, scoured anchors, multiple generators explicitly
  walked, cranny hunt. For "go ham," "leave no stones unturned," repeated what-else loops.

## Worked instances — calibration, not scope

These tune the moves and the voice. They are NOT the menu of allowed inputs: re-run the
loop from scratch on every new object, and never default to these domains.

**Instance A — a life-finance data map** (subject: what data a personal-finance system
must know; frame: national statistical classifications). The user's examples (hawker
rents, BTO prices) seeded domains; the anchor move diffed the map against the UN's
household-consumption classification, the national industrial classification, the
financial-planning profession's knowledge domains, and the government-functions
classification — every division had to map to a card or be declared a bug. The Orange
Rule turned "business = hawker" into eleven verticals; the niche shelf surfaced
domestic-worker economics, cross-border arbitrage, and miles-as-quasi-currency; the
geography generator added a "born elsewhere, cascading here" wing. The user's own
challenge — "I don't see Defence" — exposed that an *invisible* audit line is not
coverage: the fix was enumerating all 22 sections plus a 12-entry frontier shelf,
visibly.

**Instance B — a resume's full surface** (subject: one person's professional identity;
frame: occupational and skills taxonomies). Anchors: official occupational-skill
databases and skills frameworks, plus real job-ad corpora for the target roles. Axes
named first (skills, evidence, impact, keywords, identity-story — totality is per-axis).
Generators: roles held, artifacts built, tools touched, failures survived, and *things
the person does that have no name yet*. The Orange Rule splits "Python" into the basket
it actually stands for; the niche shelf catches the unnamed assets (e.g. "operates a
multi-agent personal automation estate" — a skill category so new the taxonomies lack
it, which is precisely why it is alpha). Output: the tree, plus a blindspot list =
anchor nodes the resume never touches.

## Guardrails — including this skill's own failure modes

- **The infinite map** (this skill's worst failure): totality of the *map* mutating
  into totality of *work* — an endless todo, analysis paralysis, a user buried in their
  own atlas. Defense: the map-maximally-act-selectively rule is mandatory output; gears
  cap depth; dormant-but-visible is a first-class status, not a cop-out.
- **Fake MECE** (the second failure): overlapping categories dressed as coverage, or
  "exhaustive" claimed with no anchor. Defense: the audit line is mandatory — anchors
  named or "unanchored" admitted; overlaps called out where they exist.
- **Example-seeded drift**: catching the user's orange but planting your own — your
  first enumeration is also example-seeded. Defense: the anchor diff applies to YOUR
  draft too; generators are rotated on your own output.
- **Depth without a floor**: recursing forever down one glamorous branch while the rest
  starve. Defense: breadth completes at each level before depth descends (the tree grows
  in rings, not spikes).
- Never fabricate anchor contents — fetching anchors is scour-ruled (real sources or
  labeled unverified). Never present another domain's taxonomy as this one's.

## Quality gate — falsifiable, with a redo trigger

A run is good only if ALL hold: (1) at least one external anchor was named and diffed —
or "unanchored" was stated in the output; (2) at least two different generators were
walked; (3) every user-given example appears EXPANDED into its basket, never as a leaf;
(4) the niche shelf exists and is non-empty (or the second look was reported);
(5) the full tree is visible in the output with statuses and a residual bucket;
(6) the output ends with selective-action guidance, not an implied infinite todo.
If the user replies with a concrete "I don't see X" and X belongs on the map — the run
FAILED its own audit: add X, then re-run move 1 asking *"what generator would have
caught X, and what else does that generator catch?"* — never just append X alone.

## The lineage — hidden bones

MECE (Minto's mutually-exclusive-collectively-exhaustive, the consulting canon) is the
completeness test; official statistical classifications (consumption, industry, sector,
occupation, skills frameworks) are the canonical anchor families; the type-object /
omni pattern governs this skill's place in the pack (totality is the OMNI doctrine —
scour and research-report are TYPES carrying a pointer to it; each run's map is an
OBJECT); the recursion guards descend from context-collapse research on self-expanding
structures. The skill was distilled from a live session in which the fruit→oranges→
genres→Defence corrections each forced one move into existence. Use these bones; never
recite them at runtime unless the user asks where the method comes from.
